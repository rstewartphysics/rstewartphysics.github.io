What this topic is

Digital systems work with two states, 1 and 0. Logic gates combine them to make decisions: AND, OR and NOT.

You show what a circuit does with a truth table. You write it as a Boolean expression. You build it on the logic board or in Yenka. Microcontrollers and flowcharts are on the Programmable Control (Booklet 4b) page.

Section 1 · Lesson 1

Digital signals and logic states

An analogue signal can take any value in a range. A digital signal has only two values: logic 1 (high, on, true) and logic 0 (low, off, false).

A dimmer and a light switch

Both control a lamp. A dimmer can set any brightness: that is analogue. A light switch is on or off: that is digital.

Analogue signals

Can take any value in a range. Change smoothly.

An LDR divider: Vout rises as it gets darker.

Digital signals

Only two values: ON or OFF, HIGH or LOW, 1 or 0.

A push switch is digital: pressed or not.

  • Pressed: near 5 V, logic 1 (high, on, true).
  • Released: near 0 V, logic 0 (low, off, false).

Digital inputs and outputs

Inputs give 1 or 0: push button, limit switch, guard switch, infrared sensor.

Outputs are on or off: LED, buzzer, motor, relay.

Practice — exam style

1. Describe the difference between an analogue and a digital signal. 2 marks

Answer
An analogue signal can take any value in a range (1). A digital signal has only two values, 1 or 0 (1).

2. Explain why a digital signal is not upset by a small amount of noise. 2 marks

Answer
It has only two levels, far apart (1), so a little noise can't flip a 1 into a 0 (1).
Section 2 · Lesson 2

AND, OR and NOT gates Exam

A logic gate takes digital inputs (1 or 0) and gives one digital output, Z. At National 5 you use three: AND, OR and NOT.

Past papers 2024 S1 Q1(a), (b)

The exam calls the output Z. Your booklet calls it Q.

AND gate

Z = 1 only when all inputs are 1.

Like two switches in series.

Use: the two-hand press: it moves only when both hands are on the buttons.

OR gate

Z = 1 when any input is 1.

Like two switches in parallel.

Use: an alarm that sounds when any door opens.

NOT gate

One input. The output is the opposite.

Also called an inverter.

Use: a fridge light that is on when the door is not closed.

Drawing the symbols

  1. Draw the shape.
  2. Add the input lines.
  3. Add the output line.
Watch out: draw the lines. A shape on its own scores 0. The inputs and output drawn score the mark. In 2024, only 59% of pupils in Scotland got this right.

Task: name the gate

Tap AND, OR or NOT. Every answer tells you why.

1. Name the gate. It has this truth table. Z column: 0, 0, 0, 1

2. Name the gate. It has this truth table. Z column: 0, 1, 1, 1

3. Name the gate. It has only one input.

4. Name the gate. A machine runs only when the guard is closed and the start button is pressed.

5. Name the gate. A bell rings when the front door or the back door opens.

6. Name the gate. It changes a high input to a low output.

Testing a gate

Put a switch on every input and label them A and B. Switch up = 1. LED on = 1.

Test 00, 01, 10, 11 in order, then compare with the truth table.

In class you build it on the logic board: switches J and K are A and B. No kit? Do the same test in Yenka.

Safety: never join two outputs.

Practice — exam style

1. State the output of an AND gate when A = 1 and B = 0. 1 mark

Answer
0. AND needs both inputs at 1.

2. Draw the symbol for an OR gate. 1 mark

Answer

Draw both input lines and the output line, or the mark is lost.

3. Describe what a NOT gate does. 1 mark

Answer
Its output is the opposite of its input (it inverts).
Section 3 · Lesson 3

Truth tables for combinations Exam

A truth table shows the output for every set of inputs. Work it out one gate at a time. Give each gate's output its own column, D and E. Do Z last. Each column scores a mark.

Past papers 2026 S2 Q14(d) 2025 S2 Q11(c) 2024 S2 Q14(c) 2023 S2 Q12(f) 2022 S2 Q12(a) 2021 S2 Q8(e) 2019 S2 Q9(e) 2018 S2 Q12(a)(ii) · asked in 8 of 8 exam years

How many rows?

Rows = 2n

n is the number of inputs.

  • 1 input: 2 rows
  • 2 inputs: 4 rows
  • 3 inputs: 8 rows

Filling the input columns

  • C column: 0 1 0 1 0 1 0 1
  • B column: 0 0 1 1 0 0 1 1
  • A column: 0 0 0 0 1 1 1 1

This is counting in binary, from 000 to 111. Fill them this way and no row is missed. The exam always prints them in this order.

One gate at a time

A logic circuit has no memory. The output depends only on the inputs now.

Label each gate's output: D, E. Give each one a column. Do Z last, from D and E.

The exam uses D and E for these points and Z for the output. Your booklet calls them X and Q. They mean the same thing.

Worked example: one column at a time

Complete the truth table for the logic diagram. 3 marks

  1. Column D = NOT A. 1 mark
  2. Column E = NOT B. 1 mark
  3. Column Z = D AND E. 1 mark

Each column scores its own mark. If D is wrong, Z can still score if it is right from your D.

    Section 4 · Lesson 4

    Boolean expressions Exam

    A Boolean expression writes a whole circuit in one line. AND is a dot, OR is a plus, NOT is a bar over the letter. Brackets show which gates come first.

    Past papers 2026 S1 Q5 2025 S2 Q11(d) 2024 S2 Q12(c) 2023 S1 Q3 2022 S2 Q12(b) 2021 S2 Q8(f) 2019 S1 Q6 2018 S1 Q9 · asked in 8 of 8 exam years

    Boolean for each gate

    • AND is a dot: A • B
    • OR is a plus: A + B
    • NOT is a bar: A̅

    Your booklet writes AND as A.B and the output as Q. The exam writes A • B and Z.

    From words to Boolean

    A motor turns on when the start button is pressed and the guard is in place.

    1. Name the inputs: A = start button, B = guard.
    2. "and" means AND: a dot.
    3. Z = A • B

    From a diagram to Boolean

    1. Label each first gate: D, E.
    2. Write each one: D = A • B, E = C̅.
    3. The last gate joins them: Z = D + E.
    4. Put brackets round each first gate: Z = (A • B) + C̅

    From Boolean to a diagram

    Draw Z = A̅ + (B • C).

    1. A, B, C on the left. Z on the right.
    2. The bracket first: B • C is an AND gate.
    3. A̅ is a NOT gate.
    4. The + outside the bracket is the last gate: OR.

    Draw every input and output line. A gate with a line missing loses its mark.

    Task: match the expression to the diagram

    Choose the Boolean expression for each diagram. Find the first gates (the brackets) before the last gate. Then press Check.

    Watch out: keep the brackets. (A • B) + C and A • (B + C) are different circuits. Without brackets, A • B + C can be read either way.
    Practice — exam style Booklet pp.14–15

    1. Write the Boolean expression. A warning light comes on when a door is open (A) and the engine is running (B). 1 mark

    Answer
    Z = A • B

    2. Write the Boolean expression. A pump runs when no water is detected (A). 1 mark

    Answer
    Z = A̅

    3. Draw the logic diagram for Z = (A + B) • C. 2 marks

    Answer

    1 mark for each gate wired to the right inputs.

    Section 5 · Lesson 5

    Designing logic for engineering problems Exam

    To design a control system, underline the inputs and the output. Choose AND, OR or NOT. Write the Boolean. Then draw it and check it with a truth table.

    Past papers 2023 S2 Q12(g) 2019 S2 Q9(d)

    Worked example 1: a fan

    A fan runs when it is hot and the door is not open.

    1. A = hot, B = door open. Z = fan.
    2. AND, with NOT on B.
    3. Z = A • B̅
    4. Draw it, then check: is Z = 1 only when it is hot and the door is shut?

    Worked example 2: a lift

    A lift moves when the door is closed and the floor or call button is pressed.

    1. A = door closed, B = floor button, C = call button.
    2. B OR C first, then AND with A.
    3. Z = A • (B + C)
    4. Check: the lift moves only with the door closed (A = 1).

    In class: you build this on the logic board and test all 8 rows. Switches J, K, L are A, B, C.

    From a truth table to Boolean

    1. Find each row with Z = 1.
    2. AND its inputs, with a bar on each 0.
      • Row 0 1: (A̅ • B)
      • Row 1 0: (A • B̅)
    3. OR the brackets: Z = (A̅ • B) + (A • B̅)

    Task: pick the gates for the problem

    Underline the inputs in your head, then pick. Every answer tells you why.

    1. Choose the gates. A drill runs only when the guard is down and the trigger is pressed.

    2. Choose the gates. A shop buzzer sounds when the front door or the back door opens.

    3. Choose the gates. A porch light comes on when it is not daylight.

    4. Choose the gates. A lift moves when the door is closed and the floor or the call button is pressed.

    5. Choose the gates. A fan runs when it is hot and the door is not open.

    Watch out: a bracket for every row. In 2023 only 37% of pupils in Scotland scored well on writing Boolean from a table. Write one bracket for each row with Z = 1, put a bar on every 0, then join them with +.
    Practice — exam style Booklet pp.21–22

    1. State the gate and write the Boolean. An alarm sounds when any one of three windows (A, B, C) is opened. 2 marks

    Answer
    OR (1). Z = A + B + C (1).

    2. Write the Boolean. A press works when the start button (A) and the guard (B) are on. The emergency stop (C) must not be pressed. 2 marks

    Answer
    Z = A • B • C̅

    3. Write the Boolean. A truth table has Z = 1 only in row A = 1, B = 1, C = 0. 2 marks

    Answer
    Z = A • B • C̅: one bracket, a bar on the 0.

    From a real paper: 2019 Section 2, Question 9(d). 3 marks

    Marking instructions

    One bracket for each row with Z = 1, a bar on each 0, then OR the brackets.

    Recap

    Recap and words

    What loses marks

    • A gate shape with no input or output lines.
    • Jumping straight to Z: fill D, then E, then Z.
    • Input columns out of order: count in binary, 000 to 111.
    • Boolean with the brackets left out.
    • A bar missing, or on the wrong letter.
    • Writing Boolean from a table with a bracket missing for a row with Z = 1.

    Glossary

    Analogue signal
    Can take any value in a range. Changes smoothly.
    Digital signal
    Only two values: 1 or 0, on or off.
    1 / 0
    Logic 1 / logic 0
    Logic 1 is high, on, true (near 5 V). Logic 0 is low, off, false (near 0 V).
    AND gate
    Output 1 only when all inputs are 1.
    OR gate
    Output 1 when any input is 1.
    NOT gate (inverter)
    Output is the opposite of the input.
    2ⁿ
    Truth table
    Every set of inputs and its output. Rows = 2ⁿ.
    A • B
    Boolean expression
    A circuit in one line: • for AND, + for OR, a bar for NOT.
    Combinational logic
    The output depends only on the inputs now. No memory.
