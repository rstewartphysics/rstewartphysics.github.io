🔢 L1–L3 Potential Dividers (worked examples + interactive tools)

Key idea (B2): a potential divider gives you a fraction of the supply voltage. This is the foundation of sensing and control circuits.

Formula:

Vout = (R2 / (R1 + R2)) × Vs

  • Vout is taken across R2
  • If R2 increases → Vout increases
  • If R2 decreases → Vout decreases

Worked Example 1 – Equal resistors

  • Vs = 6.0 V
  • R1 = 1.0 kΩ
  • R2 = 1.0 kΩ

Vout = (1000 / (1000 + 1000)) × 6.0 = (1000 / 2000) × 6.0 = 0.5 × 6.0 = 3.0 V

Worked Example 2 – Unequal resistors

  • Vs = 6.0 V
  • R1 = 1.2 kΩ
  • R2 = 150 Ω

Total = 1200 + 150 = 1350 Ω
Vout = (150 / 1350) × 6.0 = 0.111… × 6.0 = 0.67 V

Common mistakes (B2)

  • Using the wrong resistor in the numerator (remember: Vout across R2).
  • Mixing Ω and kΩ (convert or keep consistent).
  • Forgetting Vout must be less than Vs (sanity check).

💡 L4 Diodes & LEDs (worked examples + LED calculator)

Core facts (B2)

  • A diode lets current flow in one direction only.
  • An LED is a diode that emits light when forward biased.
  • LEDs need a protective resistor or they can be damaged.

Worked Example – LED protective resistor

  • Vs = 5.0 V
  • VLED = 2.0 V
  • I = 10 mA = 0.010 A

Voltage across resistor: VR = 5.0 − 2.0 = 3.0 V
R = V / I = 3.0 / 0.010 = 300 Ω
Choose the next sensible standard value: 330 Ω

🎛️ L6 Control Circuits (set a switching point)

What “control” means (B2)

  • A sensor changes resistance → a divider produces a changing voltage.
  • A variable resistor is used to set the switching point.
  • The circuit output controls something: LED, buzzer, motor, relay (depending on build).

Exam-style explanation starter

  • When the sensor resistance changes, the output voltage changes.
  • If the output reaches the switching threshold, the transistor turns on.
  • This allows current to flow through the output device (e.g. LED), so it turns on.

🧾 Stripboard Schematics (assessment standard + video)

What you must be able to draw (B2)

  • A stripboard layout shows component positions, not circuit symbols.
  • Label power rails: +V and 0V.
  • Show: track cuts (very important), wire links, and transistor pin positions.
  • Tracks run in straight copper strips — a mistake here causes short circuits.

Stripboard “must-do” checklist

  • Mark every track cut clearly (and double-check them before soldering).
  • Keep components low and straight (neat = reliable).
  • Transistor legs must be on separate tracks.
  • Trim leads short (avoid accidental shorts).

🔍 Fault Finding (B2 method: visual → power → signal → isolate)

Golden rule

Change ONE thing at a time and re-test. Otherwise you never know what fixed it.

Step 1 — Visual checks (power OFF)

  • Component orientation correct? (LED, diode, transistor, electrolytic capacitor)
  • Solder bridges? (accidental joins between tracks)
  • Track cuts present where needed?
  • Loose wires / exposed copper / strands touching?

Step 2 — Power checks (power ON)

  • Is the correct supply voltage present at the board?
  • Is 0 V actually 0 V everywhere it should be?
  • Does the output device have a complete path (series resistor, correct polarity)?

Step 3 — Signal checks

  • Does the divider output voltage change when the sensor changes?
  • Is that voltage reaching the transistor base?
  • If the base voltage is low, the transistor will not switch on.

Step 4 — Isolate

  • Test parts separately (e.g., LED + resistor on its own).
  • Replace one suspect component and re-test.
