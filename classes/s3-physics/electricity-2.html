Common misconception 🧨
“If I change one resistor, nothing else changes.” ✅ In dividers, changing one resistor changes the fraction and the output voltage.

🔢 L1–L3 Potential Dividers (Examples + Mission A 🧩)

Formula: Vout = (R2 / (R1 + R2)) × Vs

Worked Example ✅

  • Vs = 6.0 V
  • R1 = 1.0 kΩ
  • R2 = 1.0 kΩ

Vout = (1000 / 2000) × 6.0 = 3.0 V

Worked Example ✅

  • Vs = 6.0 V
  • R1 = 1.2 kΩ
  • R2 = 150 Ω

Vout = (150 / 1350) × 6.0 = 0.67 V

Misconception 🧨
“The voltage splits equally.” ✅ Only true if the resistances are equal.

💡 L4 Diodes & LEDs (Example + Mission B 🧩)

Worked Example ✅ LED Protective Resistor

  • Vs = 5.0 V
  • VLED = 2.0 V
  • I = 10 mA (0.010 A)

VR = 5.0 − 2.0 = 3.0 V

R = 3.0 / 0.010 = 300 Ω → choose 330 Ω ✅

Misconception 🧨
“The LED will limit its own current.” ❌ LEDs can draw too much current and break without a resistor.

🧾 Stripboard Schematics – Planning your build 🧰

How to draw stripboard schematics ✅

  • Draw component positions (not circuit symbols).
  • Copper tracks run in straight lines → label rails (+ and 0V).
  • Mark track cuts clearly (these stop shorts!).
  • Keep transistor legs on separate tracks.
  • Keep wires neat and short where possible (less mess = fewer faults).

🔍 Fault Finding – When circuits don’t work 🔧

Golden rule ✅ Change one thing at a time, then test again.

Step-by-step process 🧠

  1. Power OFF 👀 – check orientation, bridges, missing track cuts.
  2. Power ON ⚡ – check supply voltage is present where it should be.
  3. Measure 🎚️ – check divider output changes when the sensor changes.
  4. Switch point 🔄 – is the transistor base voltage reaching threshold?
  5. Output 💡 – check LED polarity + resistor present.
