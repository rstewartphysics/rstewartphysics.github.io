    Symbols + name/function drill

    Cover the names, then say the function out loud. Fast symbol recall makes Section A/B much easier.

    Component Symbol (simple) Function / what it’s used for Common mix-up
    Cell One source of potential difference (single cell). Confused with battery (multiple cells).
    Battery Two or more cells in series (higher supply voltage). Confused with cell or PV cell.
    Photovoltaic cell Turns light into electrical energy (output depends on light level). Often mistaken for a battery/cell symbol.
    Resistor Limits current / shares voltage (including dividers). Confused with variable resistor.
    Variable resistor Adjusts resistance (used to set sensitivity/threshold). Often drawn incorrectly (arrow placement).
    Diode Allows current one direction only (forward bias conducts). Confused with LED (extra arrows).
    LED Emits light when forward-biased; needs a protective resistor. Forgets series resistor / wrong polarity.
    Capacitor Stores charge; used for timing/delay/smoothing. Polarity ignored (for electrolytics).
    LDR More light → lower resistance (typical). Placed wrong way in divider for desired control.
    Thermistor (NTC) Higher temperature → lower resistance (NTC). Confused with LDR.
    ⭐ Quick symbol tipstap to open
    • Cell vs battery: battery shows multiple long/short pairs.
    • Diode vs LED: LED has extra arrows showing light.
    • LDR/NTC: both are resistors, but markings differ — don’t swap their rules.

    Exam methods (the 3 that come up all the time)

    1) Thermistor graph → resistance → voltage

    1. Read R from the graph at the given temperature.
    2. Convert current: mA → A (divide by 1000).
    3. Use V = I·R and check the answer is sensible for the circuit.

    2) LED protective resistor

    1. Find voltage across resistor: VR = Vs − VLED
    2. Convert LED current to amps.
    3. Use R = VR / I

    3) Potential divider output

    1. Define: Vout = V2 (voltage across R2).
    2. Use: Vout = ( R2 / (R1 + R2) ) × Vs
    3. Reason changes: if R2 increases → Vout increases; if R1 increases → Vout decreases.
    🗣️ “Justify” sentence stems (2-mark style)tap to open
    • Switching: “The control voltage is (above/below) the switching voltage, so the switch stage is (on/off) and the output (turns on/stays off).”
    • Divider reasoning: “When (R1/R2) increases, the fraction of the supply across R2 (increases/decreases), so Vout (increases/decreases).”
    Consistency note: On this page, Vout = V2 (the voltage across R2 in a divider).

    Core notes (open only what you need)

    Use these to fix mistakes after practice questions.

    🧾 Key Equations (core B2)must know
    V = I·R Vout (V₂) = ( R₂ / (R₁ + R₂) ) × Vₛ R_LED = (Vₛ − V_LED) / I_LED (I in amps)
    • Vs = supply voltage.
    • Vout = V2 is the voltage across R2.
    • Convert: 10 mA = 0.010 A.
    🔁 Circuit Rules Recap (from Electricity 1)B1 recap
    • Series: current same everywhere; voltages add.
    • Parallel: voltage same across branches; current splits.
    📏 Measuring in Circuits (meters)skills
    • Ammeter: series to measure current.
    • Voltmeter: parallel to measure voltage.
    • Ohmmeter: power OFF to measure resistance.
    🔢 Potential Dividers (core idea)core
    • Two resistors in series create a smaller output voltage.
    • Output is Vout = V2 (across R2).
    • If R2 increases (R1 fixed) → Vout increases.
    • If R1 increases (R2 fixed) → Vout decreases.
    🌡️ Sensors (LDRs & NTC thermistors)core
    • LDR: more light → lower resistance.
    • NTC thermistor: higher temperature → lower resistance.
    • In dividers: environment changes resistance → Vout changes → output can switch.
    🎛️ Control Circuits (recognise + explain)explain

    Recognise the goal (high/low temp or high/low light) and explain how sensor resistance changes Vout.

    • High/low light control (LDR + divider + switch stage).
    • High/low temperature control (NTC + divider + switch stage).
    🔄 Switching (NPN transistor / MOSFET)core
    • NPN BJT: small base current controls a larger collector current (used as a switch).
    • MOSFET: gate voltage controls switching (very small gate current).
    • Divider + sensor produces the control voltage for switching.
    MOSFET vs NPN — quick comparetap
    • NPN: current-controlled (base current matters).
    • MOSFET: voltage-controlled (gate voltage matters).
    💡 Diodes & LEDs (safe LED circuits)core
    • Diode/LED conducts in forward direction only.
    • LED needs a series resistor to limit current.
    • Method: VR = Vs − VLED, then R = VR / I.
    ⚠️ Common mistakes (quick fixes)fast marks
    • LED reversed: won’t light → check diode direction.
    • No protective resistor: LED can fail → add correct series resistor.
    • Measuring wrong voltage: measure Vout across R2 (in parallel).
    • Wrong rails / no 0 V reference: check V+ and 0 V continuity.
    • Short circuit / solder bridge: inspect and rework.
    • Transistor/MOSFET pins mixed: re-check pinout before powering.

    Practical Electronics short answers (Section C prep)

    🧩 Simulation (Yenka): advantages + spotting errorstap to open

    Advantages (categories to remember)

    • Safety (no damage while learning).
    • Speed (change parts quickly, reset fast).
    • Cost (no wasted components).
    • Measurement (easy voltage/current readings).
    • Fault finding (compare to “normal” readings).

    Error spotting checklist

    • Rails: V+ and 0 V connected correctly?
    • Polarity: LED/diode/capacitor/transistor correct way?
    • Missing resistor (LED needs one)?
    • Wrong sensor position in divider (R1 vs R2)?
    • Wrong connections/loose wires/short circuits?
    🛠️ Safety, pre-power checks, tool functions (quick answers)tap to open

    Soldering safety (pick 2 quickly)

    • Keep iron in the stand when not in use.
    • Work in a tidy, clear area; keep leads controlled.
    • Don’t touch the metal tip; allow time to cool.
    • Ventilation / avoid breathing fumes.

    Pre-power checks (pick 2 quickly)

    • Correct component values (especially resistors).
    • Correct orientation (LED/diode/capacitor/transistor/MOSFET).
    • No short circuits / no solder bridges.
    • Correct rails: V+ and 0 V connected properly.

    Tool functions (know these)

    • Track cutter: breaks copper track on stripboard.
    • Heat sink: protects heat-sensitive components while soldering.
    • Solder sucker: removes molten solder to fix mistakes/clear holes.

    Short answer style tip

    • Answer in bullet points.
    • Give the minimum needed for marks (2 clear points = 2 marks).

    🧪 Testing plan template (fill this into your booklet tables)tap to open

    Pre-power tests (write at least 3)

    • Component values correct (especially resistors).
    • Orientation correct (LED/diode/capacitor/transistor/MOSFET).
    • No short circuits / no solder bridges.
    • Rails correct and continuous (V+ and 0V).

    Functionality tests (write at least 3)

    • Supply voltage measures correctly at rails.
    • Measure key node voltages (including Vout) and compare to expectation/simulation.
    • Output changes correctly in the target condition (overheating warning).
    • Current not excessive; components do not heat unexpectedly.
    Testing mark protection: If something fails, record the fault + what you changed + the new result.
