📚 Lessons (L1–L9) — Get / Apply / Review

🟩 L1 — Potential Divider Theory

G — Get ready

  • Read KO: potential divider definition + equation.
  • Know: Vout is the voltage across the chosen resistor.

A — Apply

  • Use the divider equation to calculate missing values.
  • Practise “what happens if R changes?” reasoning.

R — Review

  • Can you explain “potential divider” in one sentence?
  • Can you do a divider calc without help?
🟩 L2 — Potential Divider Simulation (Yenka)

G — Get ready

  • Know what Vout is and where to measure it.
  • Know: simulation is for quick testing + safe learning.

A — Apply

  • Build divider in Yenka and measure Vout for different resistors.
  • Compare calculated vs simulated values.

R — Review

  • List 3 benefits of simulation (speed / safety / cost / easy measurement).
🟩 L3 — Potential Divider Construction + Testing

G — Get ready

  • KO: meter rules (ammeter series / voltmeter parallel).
  • Know what “pre-power” and “functionality” tests mean.

A — Apply

  • Build divider on breadboard and measure Vout with a multimeter.
  • Record: calculated vs simulated vs measured.

R — Review

  • Explain why we test before powering (protects components, avoids shorts, safer).
🟩 L4 — Diodes & LEDs (protective resistor)

G — Get ready

  • KO: diode vs LED symbol + polarity idea.
  • Know: LEDs need a series resistor to limit current.

A — Apply

  • Use the LED calculator below to practise the method.
  • Always convert mA → A.

R — Review

  • Can you explain “why a resistor is needed” in one sentence?
🟩 L5 — Special Components (capacitor, LDR, thermistor)

G — Get ready

  • KO: symbols + key rules for LDR and NTC thermistor.

A — Apply

  • State the relationships: more light → LDR resistance…?
  • Higher temperature → NTC resistance…?

R — Review

  • Can you write the rule from memory for LDR and thermistor?
🟩 L6 — Control Circuits (4 basic control circuits)

G — Get ready

  • Know the 4 types: high/low light and high/low temperature.
  • Know: sensor changes resistance → divider changes voltage → output can switch.

A — Apply

  • Measure voltages in different conditions (high vs low light/temp).
  • Adjust the variable resistor to set the switching point.

R — Review

  • For each circuit: can you say what condition makes the output turn on?
🟩 L7 — Switching Circuits (transistor/MOSFET)

G — Get ready

  • KO: NPN and MOSFET function (switching idea).
  • Know “switching voltage” = when output just turns on.

A — Apply

  • Use the Switching Builder below to practise perfect explanations.
  • Link: condition → resistance change → voltage change → switching voltage → output on.

R — Review

  • Can you write the full chain in one clear paragraph for any circuit?
🟩 L8 — Soldering & tools

G — Get ready

  • Know the purpose of: track cutter, heat sink, solder sucker.
  • Know basic soldering safety.

A — Apply

  • Practise: tidy joints, correct polarity, avoid solder bridges.

R — Review

  • Can you describe each tool in one short sentence?
🟩 L9 — Design a simple switching circuit

G — Get ready

  • Decide: what input condition triggers the output?
  • Plan labels and rails clearly (V+ and 0V).

A — Apply

  • Design → simulate → build → test → improve.

R — Review

  • Can you justify your design choices with evidence (measurements/results)?

  • LDR: more light → lower resistance.
  • NTC thermistor: higher temperature → lower resistance.
  • In a divider: if a component’s resistance decreases, the voltage across it decreases too (and the other part increases).

🧰 Electronics Skills & Testing (must-know)

🧪 Testing, meters, safety, tools (tap to open)

Pre-power checks (examples)

  • Correct component values (especially resistors).
  • Correct polarity (LED/diode/capacitor/transistor/MOSFET).
  • No short circuits / no solder bridges.
  • Rails correct (V+ and 0V continuous).

Functionality tests (examples)

  • Supply voltage correct at rails.
  • Vout changes as expected with light/temp.
  • Output device switches at the intended point.
  • Current not excessive; nothing heats unexpectedly.

Meter rules

  • Voltmeter: in parallel (measures V across a component).
  • Ammeter: in series (measures current through a circuit).
  • Resistance: power OFF to measure.

Tool functions

  • Track cutter: breaks copper track on stripboard.
  • Heat sink: protects heat-sensitive parts while soldering.
  • Solder sucker: removes molten solder to fix mistakes/clear holes.

Mark-friendly writing: answer practical questions in short bullet points (2 clear points = full marks).
