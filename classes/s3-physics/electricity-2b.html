🧪 Electronics skills & testing (what good looks like) ▾

Pre-power-up checks (before switching on):

  • Correct component values (especially resistors).
  • Correct orientation (LED/diode/capacitor/transistor).
  • No short circuits / stray wires / solder bridges.
  • Correct power rails (V+ and 0 V) and secure connections.

Functionality tests (after switching on):

  • Supply voltage is correct.
  • Key node voltages are sensible (compare to your simulation / expectation).
  • Output switches on/off in the correct conditions.
  • Nothing is overheating; current isn’t excessive.

Lessons (G / A / R)

Each lesson below matches the Success Criteria headings (L1–L9). Inside each lesson: G = Get (learn), A = Apply (do), R = Review (check).

L1 – Potential divider theory ▾
Success Criteria focus: potential divider meaning, relationships, calculations. (L1)
G – Get it (what you must understand)
  • What “potential divider” means in words.
  • How changing R1/R2 changes the output voltage.
  • What Vs, V1, V2, R1, R2 represent (use KO naming).
A – Apply (in class + homework)
  • In class: do at least 3 divider calculations (find V2, R1, or R2).
  • At home: pick 2 examples and write one sentence each: “If R1 increases, V2 ___ because …”
R – Review (quick self-check)
  • Can you explain “divider” without using the word “divide”?
  • Can you predict V2 change without calculating?
L2 – Yenka simulation (potential dividers) ▾
Success Criteria focus: simulate, measure voltages in Yenka, benefits of simulation. (L2)
G – Get it
  • Why simulation is useful before building a real circuit.
  • How to place a voltmeter correctly (in parallel).
A – Apply
  • In class: build a divider and take at least 3 voltage readings.
  • At home: write 2 advantages of simulation (safety + speed/diagnosis style).
R – Review
  • Can you explain why a voltmeter must be in parallel?
  • Can you name one mistake simulation helps you avoid?
L3 – Construction + measuring + testing basics ▾
Success Criteria focus: breadboard build, multimeter measurement, compare calc/sim/measure, pre-power & functionality tests. (L3)
G – Get it
  • How to set up power rails safely (V+ and 0 V).
  • Difference between pre-power checks vs functionality tests.
A – Apply
  • In class: build a divider; measure V2 and compare to calculation.
  • At home: list 3 pre-power checks and 3 functionality tests (short bullet points).
R – Review
  • Can you explain why testing first prevents damage?
  • Can you spot if a voltmeter is placed wrongly in a diagram?
L4 – Diodes + LEDs + protective resistor ▾
Success Criteria focus: function, why LED needs resistor, calculation, simple LED circuit. (L4)
G – Get it
  • LEDs don’t limit current well → resistor protects the LED.
  • Know what VLED and ILED mean.
A – Apply
  • In class: calculate R for a given Vs, VLED, ILED.
  • At home: use the calculator above to practise 3 different sets of values.
R – Review
  • Can you explain what happens if you forget the resistor?
  • Can you state why choosing the next highest resistor is safer?
L5 – Special components (capacitor, thermistor, LDR) ▾
Success Criteria focus: symbols + functions, LDR (light vs resistance), thermistor (temp vs resistance). (L5)
G – Get it
  • LDR: light level ↑ → resistance ↓ (typical).
  • NTC thermistor: temperature ↑ → resistance ↓.
  • Capacitor: stores charge (basic use + safety awareness).
A – Apply
  • In class: measure resistance changes in different conditions.
  • At home: write 2 “If…then…” statements (one LDR, one thermistor).
R – Review
  • Can you predict whether resistance goes up or down without guessing?
  • Can you label which component is the “sensor” in a circuit?
L6 – Control circuits (4 types) ▾
Success Criteria focus: describe + construct + test the 4 basic control circuits. (L6)
G – Get it
  • Control circuits use a sensor + potential divider to change an output.
  • “High” vs “Low” means what condition turns the output ON.
A – Apply
  • In class: build and test all 4 control circuits.
  • At home: practise the sentence builder above until you can explain each circuit smoothly.
R – Review
  • Can you explain why the variable resistor sets the “threshold”?
  • Can you state which sensor change must happen for each circuit type?
L7 – Switching circuits (transistor / MOSFET) ▾
Success Criteria focus: symbols, functions, operation of switching circuits, construct them. (L7)
G – Get it
  • NPN transistor: small base signal controls a larger current (acts like a switch).
  • MOSFET: gate voltage controls switching (very small gate current).
  • “Switching voltage” idea (when the device begins to turn on).
A – Apply
  • In class: build and test ON/OFF conditions.
  • At home: describe one circuit using the “perfect sentences” format.
R – Review
  • Can you state the purpose of the transistor in one clear sentence?
  • Can you explain what “threshold / switching” means in everyday words?
L8 – Soldering (tools + safe practice) ▾
Success Criteria focus: safe soldering, track cutter, heat sink, solder sucker. (L8)
G – Get it
  • What a good solder joint looks like (shiny, secure, not blobbed).
  • Tool purposes: track cutter / heat sink / solder sucker.
  • Safety: burns, fumes, hot tips, tidy workspace.
A – Apply
  • In class: practise soldering + fix at least one mistake using the solder sucker.
  • At home: write 2 safety rules and explain why each matters.
R – Review
  • Can you name two things you check before powering stripboard?
  • Can you describe the function of each tool without looking?
L9 – Design a simple switching circuit ▾
Success Criteria focus: design + build your own switching circuit. (L9)
G – Get it
  • Start with the requirement (“when X happens, LED turns on”).
  • Choose the correct sensor and control type (high/low light/temp).
  • Plan testing before you build (what readings should be “normal”).
A – Apply
  • In class: sketch, simulate, build, test, then solder.
  • At home: write a mini test plan: 3 pre-power checks + 3 functionality tests.
R – Review
  • Can you justify your component choices?
  • Can you explain one fault you fixed and how you found it?
🧰 Practical Electronics Assignment: Overheating Warning System (saved on this device)
You are building a prototype that gives a visual warning (red light) if a system overheats. After each stage, your assessor should check your work before you move on.
1) Analyse the problem (planning) ▾
What is overheating? What must the output do?
Sensor (thermistor) and output (red LED).
Input → Process → Output (sensor → control → LED).
You’ll set this using the variable resistor in the divider.
2) Design + simulate (Yenka) ▾
Use correct rails, component values, and labels.
Try “normal temp” vs “too hot” conditions.
So the warning triggers at the right point.
Screenshot/printout ready to stick into the booklet.
3) Construct (prototype → stripboard) ▾
Don’t go straight to stripboard.
Values, orientation, rails, no shorts.
Plan first; then transfer neatly.
Track cutter for isolation; heat sink where needed; solder sucker to fix mistakes.
Build tip: do a quick “continuity check” on tracks and cuts before you power stripboard.
4) Testing (you need evidence) ▾
Your booklet expects at least 3 pre-power-up tests and at least 3 functionality tests recorded.
Example: correct resistor values; LED orientation; no shorts; rails correct.
Write results clearly and note repairs if needed.
Example: LED on/off at correct temps; supply voltage check; compare to simulation.
Include any fixes you made.
5) Report / evaluation (finish strong) ▾
What I did + next steps after each session.
What went wrong? How did you fix it? What would you improve?
Simulation printout, stripboard plan, testing evidence.
