Topics

Open one topic, revise it, then move on.

1) Speedv = d / t

Key idea

Speed tells you how much distance is travelled each second.

v = d / t

Must know

  • Speed = m/s
  • Distance = m
  • Time = s
  • Rearrange when needed

Common mistakes

  • Forgetting the unit
  • Mixing up distance and time
  • Not using the same units all the way through
Self-check: can you calculate speed, distance, and time from the same equation triangle?
2) Forcespush / pull

Key idea

A force is a push or a pull. Forces can change speed, direction, or shape.

Must know

  • Force unit = newton (N)
  • Measured with a Newton meter
  • Forces are shown with arrows

Common mistakes

  • Forgetting the unit is N
  • Calling any arrow a force without naming it
  • Confusing force with speed
Self-check: can you explain three different things a force can do to an object?
3) Resultant force and free body diagramsbalanced / unbalanced

Key idea

The resultant force is the overall force after all forces are combined.

Must know

  • Balanced forces → resultant = 0 N
  • Unbalanced forces → motion changes
  • Arrows show direction and size

Common mistakes

  • Thinking balanced means “not moving” only
  • Ignoring direction when subtracting forces
  • Drawing arrows with no labels
Self-check: if 8 N acts right and 3 N acts left, can you find the resultant and its direction?
4) Frictionopposes motion

Key idea

Friction acts in the opposite direction to motion and can slow things down.

Must know

  • Friction can be useful or a nuisance
  • Kinetic energy can change into heat
  • Equal engine force and friction = constant speed

Common mistakes

  • Saying friction always “stops” motion instantly
  • Forgetting friction can be useful
  • Mixing up friction and resultant force
Self-check: can you give two useful examples of friction and two nuisance examples?
5) Mass and weightW = m × g

Key idea

Mass is the amount of matter. Weight is the force caused by gravity.

W = m × g

Must know

  • Mass = kg
  • Weight = N
  • g = N/kg
  • On Earth, g ≈ 10 N/kg

Common mistakes

  • Mixing up kg and N
  • Forgetting weight changes on different planets
  • Using the wrong value for g
Self-check: can you explain why mass stays the same but weight changes from planet to planet?
6) MagnetismN → S

Key idea

Magnets have north and south poles and produce a magnetic field around them.

Must know

  • Unlike poles attract
  • Like poles repel
  • Field lines are drawn N to S

Common mistakes

  • Mixing up attract and repel
  • Drawing field arrows the wrong way
  • Forgetting every magnet has two poles
Self-check: can you sketch a bar magnet and show the direction of the field lines?
7) Electromagnetscoil + core + current

Key idea

An electromagnet is a magnet made using electricity, so it can be switched on and off.

Must know

  • Use a coil of wire
  • Add an iron core
  • More coils can make it stronger
  • Higher voltage/current can make it stronger

Common mistakes

  • Forgetting the iron core
  • Saying permanent magnets can be turned off
  • Not linking strength to coils or supply
Self-check: can you describe two ways to make an electromagnet stronger?
