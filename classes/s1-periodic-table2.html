How to use the Periodic Table

These are the steps most questions expect you to use.

Quick method

  1. Find the element box.
  2. Read the symbol (capital letter first, then lowercase if needed).
  3. Read the atomic number (this is the number of protons).
  4. Use the zig-zag line to decide metal or non-metal.
  5. Group = column, Period = row.
Common slip: Writing the symbol wrongly (e.g. NA instead of Na) loses marks.

Separating mixtures (quick methods)

You are expected to choose the correct method and explain why.

Choosing rule: Filtration = insoluble solid + liquid. Evaporation = soluble solid + liquid. Chromatography = dyes/inks.

Filtration

Separate an insoluble solid from a liquid.

  1. Put filter paper in funnel.
  2. Pour mixture through.
  3. Solid stays (residue). Liquid goes through (filtrate).
Key word: insoluble

Evaporation

Separate a soluble solid from a liquid.

  1. Heat the solution gently.
  2. Water evaporates.
  3. Solid crystals remain.
Key word: soluble

Chromatography

Separate dyes/inks dissolved in a solvent.

  1. Draw a pencil baseline.
  2. Spot ink above the solvent level.
  3. Let solvent rise and separate colours.
Key word: baseline
Common mistakes (tap to open)avoid losing marks
  • Chromatography: using pen for the baseline (must be pencil).
  • Chromatography: ink spot placed in the solvent (must be above).
  • Filtration vs evaporation: mixing up soluble and insoluble.

      Key words

      Learn these definitions. They help with longer questions (and how marks are awarded).

      Key words (tap to open)term → definition

      Element

      A pure substance made of only one type of atom.

      Atom

      The smallest particle of an element.

      Molecule

      Two or more atoms joined together.

      Compound

      Two or more elements joined together. A compound’s properties are different from the elements it is made from.

      Mixture

      Two or more substances mixed together but not joined. Mixtures can be separated physically.

      Symbol

      One or two letters that represent an element (capital first, then lowercase if needed).

      Atomic number

      The number of protons in the nucleus of an atom.

      Periodic Table

      A table of all known elements ordered by atomic number and arranged into groups and periods.

      Group

      A vertical column in the Periodic Table. Elements in the same group have similar properties.

      Period

      A horizontal row in the Periodic Table.

      Chromatography

      A method used to separate the substances in a mixture of dyes/inks.

      Filtration

      A method used to separate an insoluble solid from a liquid.

      Evaporation

      A method used to separate a soluble solid from a liquid by heating to remove the liquid.

      Tip for longer questions: Use the key word, then give one extra detail (example, reason, or result).
