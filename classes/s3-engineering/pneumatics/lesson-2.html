Concept 1

Boxes and ports

Key words

Box
one state of the valve.
Port
a hole where a pipe joins the valve.
3/2
3 ports and 2 states.

A valve symbol is drawn as boxes. Each box is one state of the valve. This valve has 2 boxes: pressed and at rest.

The ports join the bottom box, the one at rest.

PortWhat it does
1Air in, from the air supply.
2Air out, to the cylinder.
3Exhaust: used air leaves here.

3 ports and 2 states: we call it a 3/2 valve.

The real valve has the same three ports. Its symbol is printed on the plate, so you can always check which port is which.

Practice 1

1. State how many states a 3/2 valve has.

Answer
2. One box for each state: pressed and at rest.

2. State which port the used air leaves from.

Answer
Port 3, the exhaust.

You can now…

  • say what a box in a valve symbol means.
  • name ports 1, 2 and 3.
Concept 2

Inside the boxes

Key words

Arrow
the path the air takes.
T
that port is blocked.
Spring
pushes the valve back.
PartWhat it means
ArrowThe path the air takes.
TThat port is blocked.
ButtonPush it to change state.
SpringPushes the valve back.

Read the box that sits on the ports. At rest, the T sits on port 1, so the air supply is blocked. The arrow joins port 2 to port 3, so air can leave the cylinder.

Practice 2

1. State what a T in a box means.

Answer
That port is blocked.

2. State what pushes the valve back when you let go.

Answer
The spring.

You can now…

  • read the arrow and the T in a box.
  • say what the button and the spring do.
Concept 3

Same valve, different push

Same boxes, same ports. Only the part on top changes: it is what pushes the valve.

Button

A finger pushes it.

Lever

A hand moves it.

Roller

A train presses it as it goes past.

Practice 3

1. Name the valve a hand moves.

Answer
A 3/2 lever valve.

2. State what is the same on all three symbols.

Answer
The boxes and the ports. Only the part on top changes.

You can now…

  • tell a button, a lever and a roller valve apart.

Air on

Press and let go

The lever gate you build. Tap the picture, or the button beside it, to move the air one step. Orange is air.

Practice 5

Spot the mistake. A pupil wrote: “When I let go, air goes into port 3 and pushes the rod back in.” Find the mistake. Fix it.

Answer
Air goes out of port 3. Port 1 is blocked. The spring pushes the rod in.

You can now…

  • say what a 3/2 valve does when it is pressed.
  • say what it does when it is let go.
The build

The lever gate

The job

  1. When the lever is pushed, the rod moves out.
  2. When the lever is let go, the rod moves back in.
  3. The drawing shows every symbol and port.

  2. Manifold (air supply)
  3. 3/2 lever valve
  4. Single-acting cylinder
  5. Tubing
  6. Goggles, one each

Check your test
  • i Yes: air from the valve pushed the rod out.
  • ii Yes: the cylinder's spring pulled the rod back.
  • iii Let go: the air went out of the valve's exhaust, port 3.
