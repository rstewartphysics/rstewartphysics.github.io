Routine

Keep it simple: practise → mark → correct → re-do.

One routine that works

  1. Open the Past Paper Question Finder 2017–2025.
  2. Pick one topic from the list.
  3. Do the questions without notes.
  4. Mark carefully.
  5. Write corrections (full sentence / correct unit / correct method).
  6. Re-do the same topic later until it’s reliable.
What counts as a “proper correction”do this
  • Write the correct sentence (not “I understand”).
  • Fix the exact mistake: wrong symbol, wrong unit, wrong method line, wrong circuit rule.
  • If it’s a calculation: show working + final answer + unit.

Common ways marks are lost

  • Missing units / wrong units.
  • Wrong symbol or incorrect component value (e.g. resistor code).
  • Stating a rule without applying it (e.g. series/parallel behaviour).
  • Vague logic answers (not naming the gate/output clearly).
  • Not explaining how you tested / simulated a circuit.
