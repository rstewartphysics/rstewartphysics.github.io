System Overview

Building conceptual fluency before practical assembly

🧠 Why We Use a Three‑Board System (Pedagogical Rationale)

Separating the build into Input → Process → Output reduces cognitive load and mirrors how engineers design real systems. Students learn to reason about signals, flow, and conditions step‑by‑step rather than all at once.

  • Input board: generates two clean logic signals
  • Process board: logically decides when output should activate
  • Output board: displays behaviour (LED driver + 555 astable)
🛠 Universal 6‑Step Build Method (Sequenced Scaffold)

A repeatable routine promotes procedural memory and reduces errors.

  1. Highlight inputs, outputs, and power pins on the schematic.
  2. Mark power rails clearly (+V top, 0V bottom).
  3. Place the IC first → ensures track cuts & orientation clarity.
  4. Add resistors/sensors → build signal pathways.
  5. Add link wires → joining non‑touching strips.
  6. Add LEDs/capacitors last → easier polarity checking.
🎨 Colour Coding for Cognitive Safety

Consistent colour rules improve debugging and reduce mis‑identification.

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output
🖼 Visualising the Whole System First
Complete System (Yenka)

Students build with greater accuracy when they mentally visualise the whole system before touching components.

🧩 Functional Summary

Input → Process → Output is a core computing and electronics pattern. Understanding this early supports future work with microcontrollers, FPGAs, and logic circuits.

🔧 Troubleshooting Model (Teaching metacognition)

Students learn how to diagnose faults systematically rather than guessing.

  • Check rails
  • Check orientation
  • Check node connections
  • Check polarity
  • Match schematic → stripboard

Input Board

Thermistor + Switch → Logic signals that the system can reason with.

🧩 Concept: What the Input Board Actually Does
Input Section

The Input board transforms physical conditions (temperature & switch state) into two clean logic levels the AND gate can use.

🔧 Components & Cognitive Signposting
  • Thermistor RT → senses temperature
  • R1, R2, R3 → form stable dividers
  • Switch SW1 → manual override input

Colour rules help students see the logic flow across boards.

🌡 How Voltage Dividers Work (Misconceptions Addressed)

Students often think “thermistors create signals by themselves.” This section corrects that:

  • Thermistor + resistor = voltage divider
  • Higher temperature → lower resistance → higher output voltage

Voltage dividers are the foundation of all analogue sensing.

✔ Self‑Checking Routine

Students independently verify correctness before progressing — a key metacognitive habit.

  • TempOut increases with heat?
  • SwitchOut changes cleanly?
  • Colours consistent?

Process Board – AND Gate

Combining two logic inputs into one meaningful control signal.

🧩 Concept: Why AND Logic?

Students learn conditional logic in a physical context: “Output happens only if conditions A AND B are true.” This prepares them for computational thinking and programming.

💠 Pin Connections (Reducing Spatial Confusion)
  • Pin 1 = TempOut
  • Pin 2 = SwitchOut
  • Pin 3 = Output
  • Pin 14 = +V, Pin 7 = 0V

Clear mapping prevents the common error of misreading IC orientation.

🔌 Power & Link Logic

Students understand why ICs need power rails and track isolation:

  • Each pin must be electrically isolated
  • Track cuts define node boundaries
  • Colour choices reinforce node identity
✔ Diagnostic Skills

Students learn to analyse behaviour logically before adjusting hardware:

  • If TempOut HIGH + SwitchOut HIGH → AND output must be HIGH
  • If not → check pins 1,2,3 continuity
  • Reconfirm all cuts

Output Board – 555 LED Flasher

Making the invisible logic visible to students.

🧩 Concept: Converting Logic into Behaviour

The 555 astable converts a logic “GO” signal into a timed sequence that students can visually interpret. This bridges logic circuits and timing systems.

⏱ Understanding the Timing Network

The R4–R5–C1 combination controls flash rate. This teaches:

  • Capacitor charge/discharge behaviour
  • Timing constants
  • Relationship between resistance, capacitance and period
💡 LED Logic (Making Logic States Visible)
  • Green LEDs = HIGH
  • Red LEDs = LOW

A dual‑colour output is a powerful formative assessment tool — students instantly see correct/incorrect operation.

✔ Self‑Diagnosis
  • Does pin 3 toggle?
  • Are LEDs correctly oriented?
  • Is C1 polarity correct?
