🛠 Build Method — Universal 6-Step Stripboard Process

These six steps work for ANY stripboard project. They form the core procedural knowledge for N5 practical electronics.

Universal 6-Step Method

  1. Print the schematic and highlight every input, output and power pin. Ensures students form a mental model before placing components.
  2. Mark the power rails.
    Red = +V, Black = 0V. This reduces the most common early error: reversed rails.
  3. Place the IC first.
    Stripboard has no centre gap → track cuts must be placed under every pin.
  4. Add resistors and sensors.
    This forces students to check schematic “nodes” rather than positions.
  5. Add link wires.
    If two schematic points join but copper strips don’t, a wire must be added.
  6. Add LEDs and capacitors last.
    Polarity checks happen here to prevent rework.

Pedagogy: This staged method prevents cognitive overload and mirrors industry PCB design practice.

🎨 Stripboard Colour Code (N5 Standard)

A single colour per signal prevents logic-tracking errors and accelerates debugging.

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND Output
  • Purple = Timing Node

Pedagogy: Colour-coding offloads working memory by making hidden signals visible.

🔄 Schematic → Stripboard Translation Rules

Understanding how a schematic becomes a physical stripboard layout is a core N5 Electronics skill.

Key Rules

  • Schematic diagrams show logical layout — not physical position.
  • A node in the schematic = a connected copper strip in real life.
  • If the schematic shows a connection but strips don't touch → add a link wire.
  • Track cuts replicate the breadboard centre gap.
  • Follow pin numbers, not positions.

Pedagogy: Corrects the biggest novice misconception: “stripboard should look like the picture”.

Optimisation Techniques

  • Minimise track cuts

  • Avoid loops in ground rails

Input Board

Thermistor + Switch → two analogue/digital signals
🧩 What the Input Board Does
Yenka – Input Section
Input Stripboard

Creates two logic signals for the AND gate: TempOut (blue) and SwitchOut (green).

Pedagogy: Dual-coding + clear functional framing.

🔧 Components & Wiring
  • RT — Thermistor
  • R1 — 4.7kΩ pulldown
  • R2 — 10kΩ pull-up
  • R3 — 10kΩ pulldown
  • SW1 — Switch
  • +V rail (top), 0V rail (bottom)

Colour coding: Blue = TempOut, Green = SwitchOut, Red = +V, Black = 0V

Pedagogy: Differentiates roles of resistors—reducing misconceptions about divider behaviour.

🌡 Temp & Switch Dividers

Thermistor Divider

RT (to +V) and R1 (to 0V) form a voltage divider. ↑ Temperature → ↓ RT → ↑ TempOut.

Switch Divider

  • R2 pulls HIGH
  • R3 pulls LOW
  • SW1 moves the centre point

Pedagogy: Corrects misconception that “the switch sends voltage”.

✔ Build Checkpoint & Mistakes

Checkpoint

  • TempOut responds to temperature?
  • SwitchOut switches cleanly?
  • RT → R1 chain correct?
  • Colours unique?

Common Mistakes

  • Thermistor to 0V → inverted behaviour
  • Switch centre pin wrong strip → stuck HIGH/LOW
  • R2/R3 swapped → floating node
  • Reused colours → untraceable

Process Board – AND Gate

74HC08 combines two logic inputs
🧩 What the Process Board Does
Yenka – AND Section
Process Stripboard

AND gate outputs HIGH only when both TempOut & SwitchOut are HIGH.

💠 Pin Connections
  • Pin 1 = TempOut
  • Pin 2 = SwitchOut
  • Pin 3 = AND Output
  • Pin 14 = +V
  • Pin 7 = 0V

Notch = Pin 1. IC must face left.

🔌 Power & Links
  • Red → Pin 14
  • Black → Pin 7
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND Output → Output board

Every pin must be isolated with a track cut.

✔ Checkpoint & Mistakes

Checkpoint

  • Pin 1/2 respond correctly?
  • Pin 3 only HIGH when both inputs HIGH?
  • All track cuts confirmed?

Common Mistakes

  • Pins 1/2 swapped → wrong logic
  • Missing track cut → shorted pins
  • Output wired to wrong strip

Output Board – 555 LED Flasher

Runs only when AND output is HIGH
🧩 What the Output Board Does
Yenka – Output Section
Output Stripboard

Contains the 555 astable that alternates red/green LEDs. Enabled only when AND output = HIGH.

⏱ Timing Network (R4, R5, C1)
  • R4: +V → Pin 7
  • R5: Pin 7 → Timing Node (pins 2/6)
  • C1: Timing Node → 0V

Long leg of C1 = timing node. Short leg = 0V.

💡 LED Connections

Green LEDs (HIGH)

  • Pin 3 → resistor → LED → 0V

Red LEDs (LOW)

  • +V → resistor → LED → Pin 3

Blue = 555 output.

✔ Checkpoint & Mistakes

Checkpoint

  • Pin 3 toggles?
  • Green LEDs on HIGH?
  • Red LEDs on LOW?
  • C1 polarity correct?

Common Mistakes

  • C1 reversed → no oscillation
  • Pins 2/6 not linked → broken timing node
  • R4/R5 swapped → incorrect frequency
  • LEDs reversed → no light
