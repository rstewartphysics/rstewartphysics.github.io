System Overview

These three stripboards form the complete logic chain: Input → Process → Output.

This system uses three linked boards to sense inputs, make logic decisions, and control the output flasher. Each board does one job:

  • Input Board: Creates two clean logic signals (TempOut and SwitchOut).
  • Process Board: Uses a 74HC08 AND gate to check both signals.
  • Output Board: Runs a 555 LED flasher only when the AND condition is TRUE.

Key idea: The boards look different from the Yenka schematic layout, but the connections are identical. Follow the labelled signals (blue, green, yellow) across all three boards.

Input Board

Yenka – Input Section
Input Stripboard

⭐ Part 1 — What the Input Board Does

The Input board creates two logic signals: TempOut (blue wire) and SwitchOut (green wire). These go to the AND gate on the Process board.

1 — Identify all components

  • RT — Thermistor (temperature sensor)
  • R1 — 4.7 kΩ pulldown (TempOut divider)
  • R2 — 10 kΩ pull-up (SwitchOut divider)
  • R3 — 10 kΩ pulldown (SwitchOut divider)
  • SW1 — Switch input
  • +V rail — top copper strip
  • 0V rail — bottom copper strip

2 — Thermistor voltage divider (TempOut)

RT is connected between +V and TempOut. R1 is connected between TempOut and 0V.

Meaning: High temperature → RT decreases → TempOut voltage increases.

3 — Switch voltage divider (SwitchOut)

  • R2 pulls the line HIGH
  • R3 pulls the line LOW
  • SW1 connects the centre pin to the SwitchOut node

SW pressed = HIGH. SW released = LOW.

4 — Output lines to Process board

  • Blue → TempOut
  • Green → SwitchOut

5 — Link wires

These join points that are connected in the schematic but not on the stripboard tracks:

  • Red → +V extensions
  • Black → Ground rails
  • Blue → TempOut
  • Green → SwitchOut

Input Board Complete ✔ You now have two clean logic inputs feeding the AND gate.

Process Stripboard

⭐ Part 2 — What the Process Board Does

The Process board contains a 74HC08 AND gate. It outputs HIGH only when both TempOut and SwitchOut are HIGH.

1 — Identify the parts

  • 74HC08 IC — contains four AND gates
  • Using Gate 1: pins 1 (A), 2 (B), 3 (Y)
  • Pin 14 → +V, Pin 7 → 0V
  • Blue wire → TempOut → pin 1
  • Green wire → SwitchOut → pin 2
  • Yellow wire → AND output → Output board

2 — IC orientation and track cuts

The stripboard has no centre gap, so each IC pin sits on its own isolated copper pad. Track cuts (red Xs in photo) prevent unwanted joins.

3 — Power rails

  • Pin 14 → +V (top red rail)
  • Pin 7 → 0V (bottom black rail)

4 — Inputs from the Input board

  • TempOut → pin 1
  • SwitchOut → pin 2

5 — AND output wiring

  • Pin 3 is the AND output
  • This is taken by a yellow link wire to the Output board

Logic rule: 1 AND 1 = 1 → enables the 555 flasher.

6 — Link wire summary

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output

Process Board Complete ✔ The AND output now controls the 555 flasher.

⭐ Part 3 — What the Output Board Does

The Output board contains a 555 astable flasher. It only runs when the AND gate output is HIGH.

1 — Identify all parts

  • 555 IC — creates square wave output
  • R4 — timing resistor 1
  • R5 — timing resistor 2
  • C1 — timing capacitor
  • Red LEDs — LOW output indicator
  • Green LEDs — HIGH output indicator

2 — Pin connections

  • Pin 1 → 0V
  • Pin 8 → +V
  • Pins 2 and 6 linked — timing node
  • Pin 3 — output to LEDs

3 — Timing network

  • R4: +V → pin 7
  • R5: pin 7 → timing node (pins 2/6)
  • C1: timing node → 0V

Note: Reversing C1 stops the oscillator.

4 — LEDs

Green LEDs (HIGH output)

  • Pin 3 → resistor → LED → 0V

Red LEDs (LOW output)

  • +V → resistor → LED → Pin 3

Opposite direction = opposite behaviour → they flash alternately.

5 — AND gate trigger input

The yellow wire from the Process board goes into pin 2. This means the flasher only runs when TempOut AND SwitchOut are both TRUE.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Yellow = AND trigger
  • Blue = 555 output
  • Purple = timing node

Output Board Complete ✔ Your full system is now functional — sense → logic → flashing output.
