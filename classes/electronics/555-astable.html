How the 555 Astable Works

This section explains the core idea behind the 555 astable circuit. Important misconception: The capacitor does NOT fully charge or fully discharge. It only moves between 1/3 and 2/3 of the supply voltage.

📘 Click to expand explanation

The capacitor charges through R1 and R2 until it reaches 2/3 of the supply voltage. The 555 then switches LOW and the capacitor discharges through only R2 until it drops below 1/3. This loop repeats forever, creating a continuous square wave.

🔍 Spot the Difference: Schematic vs Stripboard

🟦 1. Shape Differences

Schematics are tidy and logical. Stripboards follow the copper strips, so parts move around to fit.

🟥 2. IC Orientation

The 555 must sit across the centre gap so each pin is on a separate strip.

🟧 3. Resistors Move

R1 and R2 appear in different places, but they still connect to the same pins.

🟩 4. Capacitor Position

C1 is placed lower on the board but still links pin 2/6 to 0V.

🟪 5. LED Positions

The LEDs shift sideways but still connect to pin 3 through their resistors.

🟫 6. Power Rails

On stripboard, the rails are long strips (red = +9V, black = 0V).

🟨 7. Wires Appear

Stripboard layouts include link wires where strips must be joined.

Key idea: The layout changes, but the connections stay identical.

🎓 Student-Friendly Explanation

This circuit uses a 555 timer to make two LEDs flash one after the other. The 555 never stays stable — it continuously switches between HIGH and LOW.

🌟 How it works

1. The capacitor is constantly charging and discharging.
Its voltage rises and falls between 1/3 and 2/3 of the supply voltage.

2. R1 and R2 set the speed of the flashing.
• Bigger resistors = slower charge/discharge = slower flashing
• Smaller resistors = faster flashing

3. The 555 output switches ON and OFF repeatedly.
HIGH → green LED lights
LOW → red LED lights

4. The 680Ω resistors protect the LEDs by limiting the current so they don’t burn out.

The whole circuit is a repeating cycle: Charge → HIGH → Discharge → LOW → repeat forever.

🛠️ Stripboard Build Guide

Step 1 — Identify the parts (match to the schematic first)

Before placing anything, make sure you can point to each part on BOTH the schematic and stripboard layout:

  • 555 IC (8-pin timer chip)
  • R1 and R2 (timing resistors)
  • C1 (timing capacitor)
  • Green LED + 680 Ω resistor
  • Red LED + 680 Ω resistor
  • +9 V power rail (red strip)
  • 0 V / Ground rail (black strip)

Why this matters: The stripboard looks different, but the connections must match the schematic exactly.

Step 2 — Place the 555 (with the correct track cuts)

The stripboard you are using does not have a centre gap. Instead, the copper tracks must be cut under the chip pins where shown by the red X symbols.

  • Each pin needs its own isolated copper pad
  • The notch or dot marks pin 1
  • Pins 1–4 appear on one side of the chip, pins 5–8 on the other

Common mistake: Forgetting a track cut causes multiple pins to short together, stopping the circuit.

Step 3 — Set up the power rails correctly

Use the long horizontal copper strips:

  • Red strip = +9 V
  • Black strip = 0 V (ground)

Check with a continuity tester so you can see that each rail runs the full length of the board.

Step 4 — Fit R1 and R2 to the correct pins

Match them exactly to the schematic pin numbers:

  • R1: pin 8 (Vcc) → pin 7 (Discharge)
  • R2: pin 7 (Discharge) → pins 6/2 (Threshold + Trigger node)

Pupil tip: Pins 2 and 6 must be linked on the stripboard — they form one timing node.

Step 5 — Add the capacitor C1 (polarity matters!)

C1 connects between:

  • Linked pins 2/6
  • 0 V rail

If using an electrolytic capacitor:

  • Long leg = + (goes to pins 2/6)
  • Short leg = – (goes to 0 V)

Common mistake: Putting C1 to +9 V. It must go to ground.

Step 6 — Add the LEDs + their 680 Ω resistors

Green LED (ON when output is HIGH)

  • Pin 3 → 680 Ω resistor → 0 V

Red LED (ON when output is LOW)

  • +9 V → 680 Ω resistor → pin 3

Why they behave differently: The red LED is connected the opposite way round, so it lights when the output is LOW.

Step 7 — Add the link wires

Add short coloured wires wherever copper tracks alone cannot create the required connection.

  • Yellow links connect timing nodes
  • Blue links join LED paths
  • Red/black links extend power rails

Key rule: If two things are connected on the schematic but not touching on the stripboard, add a link.

Final Reminder

The stripboard layout looks completely different, but EVERY electrical connection matches the schematic exactly.
If something doesn’t work, check pin numbers — not picture positions.
