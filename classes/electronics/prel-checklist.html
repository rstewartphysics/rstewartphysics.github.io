✅ Start here (simple)

✅ What you must do every lesson (2–3 minute routine)

  • Date your work (logbook entry or section progress).
  • Tick what you completed in the booklet (note if something didn’t work).
  • Keep evidence clear: labels, values, test results, repair notes readable.
  • Hand the booklet in at the end for teacher check/initials.
💾 Ticks on this page (tap to open)
  • Your ticks are saved on this device (browser storage).
  • They don’t replace your booklet evidence.
  • If you’re on a shared device, use Reset progress.

🗓️ Timeline (Week Beginning targets)

  • W/B (end of December): Read the brief + understand required behaviour (light/dark + flashing sequences).
  • W/B 05 Jan: Start Analysis & Design — block diagram + begin Yenka.
  • W/B 12 Jan: Get Yenka working + start the component list (IDs, values, quantities).
  • W/B 19 Jan: Complete stripboard layout diagram + add test points + colour wiring lines.
  • W/B 26 Jan: Deadline: Planning & Analysis finished by end of January.
  • W/B 02 Feb: Construction begins — build sub-systems + test as you go.
  • W/B 09 Feb: Continue construction + pre power-up checks + early functionality tests.
  • W/B 23 Feb onward: Connect sub-systems + wiring schedule + full testing + repairs.
  • March: Finish build, fix faults, full system test evidence, logbook kept up to date.
  • Final week before Easter: Evaluation + final checks + submit.

⭐ End-of-January “Ready to Build” checkpoint

  • Block diagram complete + clearly labelled
  • Yenka works exactly as required + labels + test points
  • Component list complete (IDs, values, quantities, supplier/price if required)
  • Stripboard layout complete (symbols, track cuts, colours, test points, labels)
  • I know what I’m building first in W/B 02 Feb
