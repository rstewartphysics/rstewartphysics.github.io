🛠 Build Method — Universal 6-Step Stripboard Process

These six steps work for ANY stripboard project: Input → Process → Output.

Universal 6-Step Method

  1. Print the schematic and highlight every input, output and power pin.
    Understand the function of every connection before placing parts.
  2. Mark the power rails.
    • Red = +V (top strip)
    • Black = 0V (bottom strip)
    Confirm continuity end-to-end.
  3. Place the IC first.
    Stripboard has no centre gap → cut copper under every pin.
    Pin 1 always goes on the left.
  4. Add resistors and sensors.
    Make sure each pin lands on the correct isolated strip.
  5. Add link wires.
    Each schematic connection must exist physically — if strips don’t touch, add a wire.
  6. Add LEDs, capacitors and terminal blocks last.
    Check LED and capacitor polarity carefully.

Rule: Follow the schematic, not the picture. Stripboard layouts can vary — the schematic never lies.

🎨 Stripboard Colour Code (N5 Standard)

Every wire colour must be meaningful. Follow the N5 Electronics convention:

  • RED = +V
  • BLACK = 0V
  • Every other signal → unique colour
    (blue = TempOut, green = SwitchOut, yellow = AND Output, purple = timing node)

This prevents tracing errors and matches S4–S6 project standards.

🔧 Troubleshooting Checklist
  • Power rails correct? (+V and 0V continuous)
  • IC pins isolated? Every track-cut in place
  • Each signal colour used once? Avoid trace errors
  • Capacitor polarity correct?
  • LED polarity correct?
  • Compare every connection to the schematic.

If stuck → continuity-test each strip. Follow the copper, not your eyes.

🔄 Schematic → Stripboard Translation Rules

Understanding how a schematic becomes a physical stripboard layout is a core N5 Electronics skill.

Key Rules

  • Schematic diagrams show logical layout (clean, spaced, easy to read).
  • Stripboards follow copper tracks — parts move to wherever they must fit electrically.
  • A “node” in the schematic = a connected copper strip on the board.
  • If the schematic shows a connection but the strips don’t touch, you MUST add a link wire.
  • Track cuts replace the centre gap used in breadboards.
  • Follow pin numbers, not the picture — especially for ICs.

These rules help you translate any schematic to stripboard, no matter how complex the circuit becomes.

⚙ Advanced: Optimising Stripboard Layouts

For students who want to improve their engineering design skills, these optimisation principles greatly improve build quality.

Optimisation Techniques

  • Minimise wire length → reduces noise and confusion.
  • Keep symmetry where possible → makes debugging easier.
  • Use the fewest track cuts you can → more reliable board.
  • Group signals by colour → follow N5 standard convention.
  • Avoid unnecessary loops on ground rails → prevents noise.
  • Use design language: red = +V, black = 0V, and every other signal gets its own colour.

These techniques help you progress toward Higher Electronics and real-world PCB thinking.

Input Board

Input Stripboard

⭐ Part 1 — What the Input Board Does

The Input board creates two clean logic signals that feed into the AND gate:
TempOut (blue) SwitchOut (green)

1 — Identify all components

  • RT — Thermistor
  • R1 — 4.7 kΩ pulldown
  • R2 — 10 kΩ pull-up
  • R3 — 10 kΩ pulldown
  • SW1 — Switch
  • +V rail — top copper strip
  • 0V rail — bottom copper strip

2 — Thermistor voltage divider

RT (to +V) and R1 (to 0V) form a voltage divider. High temperature → low RT → higher TempOut voltage.

3 — Switch voltage divider

  • R2 pulls SwitchOut HIGH
  • R3 pulls SwitchOut LOW
  • SW1 drives the centre pin of the divider

4 — Output lines

  • Blue = TempOut
  • Green = SwitchOut

5 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut

Input Board Complete ✔

✔ Build Checkpoint

  • Does TempOut change when you warm/cool the thermistor?
  • Does SwitchOut clearly switch between HIGH and LOW?
  • Are RT → TempOut → R1 forming a clean voltage divider?
  • Is each signal wire colour unique (blue = TempOut, green = SwitchOut)?

⚠ Common Mistakes (and How to Fix Them)

  • Thermistor wired to 0V instead of +V → TempOut inverts (fix: RT must go to +V).
  • Switch centre pin on the wrong strip → always HIGH or always LOW (fix: centre pin must touch the SwitchOut node).
  • R2 and R3 swapped → output floats or becomes noisy (fix: R2 is pull-up, R3 is pull-down).
  • Signal wires sharing colours → easy to mis-trace (fix: TempOut = blue, SwitchOut = green).

Process Board – AND Gate

Yenka – AND Section
Process Stripboard

⭐ Part 2 — What the Process Board Does

The Process board uses a 74HC08 AND gate. Output = HIGH only when TempOut AND SwitchOut are HIGH.

1 — Identify parts

  • 74HC08 AND gate IC
  • Using Gate 1 → pins 1 (A), 2 (B), 3 (Y)
  • Pin 14 → +V
  • Pin 7 → 0V
  • Blue → TempOut → pin 1
  • Green → SwitchOut → pin 2
  • Yellow → AND output → Output board

2 — IC orientation

No centre gap → each pin sits on an isolated copper pad. Track cuts isolate all pins.

3 — Power

  • Pin 14 → +V
  • Pin 7 → 0V

4 — Inputs

  • Pin 1 = TempOut
  • Pin 2 = SwitchOut

5 — Output

Pin 3 is the AND output → yellow wire → triggers the 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output

Process Board Complete ✔

✔ Build Checkpoint

  • Does pin 1 (TempOut) go HIGH/LOW correctly?
  • Does pin 2 (SwitchOut) go HIGH/LOW correctly?
  • Does pin 3 (AND Output) only go HIGH when BOTH inputs are HIGH?
  • Are all IC pins isolated by confirmed track cuts?

⚠ Common Mistakes (and How to Fix Them)

  • Pin numbers misread → AND gate behaves incorrectly (fix: notch marks pin 1; check orientation).
  • Missing track cuts → two IC pins short together (fix: verify every red-X cut individually).
  • Blue/green inputs placed one strip off → wrong signal into pin 1 or 2 (fix: continuity-test each input).
  • AND output wired to wrong strip → 555 never starts (fix: pin 3 → yellow wire → Output board).

Output Board – 555 LED Flasher

Yenka – Output Section
Output Stripboard

⭐ Part 3 — What the Output Board Does

The Output board contains a 555 astable that flashes green & red LEDs. It only runs when the AND gate output (yellow wire) is HIGH.

1 — Identify all parts

  • 555 IC
  • R4, R5 — timing resistors
  • C1 — timing capacitor
  • Red LEDs — LOW output
  • Green LEDs — HIGH output

2 — Power pins

  • Pin 1 → 0V
  • Pin 8 → +V

3 — Timing network

  • R4: +V → pin 7
  • R5: pin 7 → timing node (pins 2/6)
  • C1: timing node → 0V

4 — LEDs

Green LEDs (HIGH)

  • Pin 3 → resistor → LED → 0V

Red LEDs (LOW)

  • +V → resistor → LED → pin 3

5 — AND gate trigger

Yellow wire from Process → pin 2 of 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Yellow = AND output
  • Blue = 555 output
  • Purple = timing node

Output Board Complete ✔

✔ Build Checkpoint

  • Does the 555 output (pin 3) toggle between HIGH and LOW?
  • Do green LEDs light only on HIGH?
  • Do red LEDs light only on LOW?
  • Is C1 polarity correct?
  • Is the yellow AND-signal wire definitely reaching pin 2?

⚠ Common Mistakes (and How to Fix Them)

  • C1 reversed → no oscillation (fix: long leg → pins 2/6, short leg → 0V).
  • Pins 2 and 6 not linked → timing node missing (fix: add vertical link).
  • Pin 3 misused → LEDs don’t alternate (fix: blue link must go from pin 3 to LED network).
  • R4 & R5 swapped → timing becomes incorrect (fix: R4 = +V→7, R5 = 7→2/6).
  • LEDs reversed → no light (fix: check polarity carefully).
