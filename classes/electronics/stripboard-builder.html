Stripboard Builder – Interactive Guide

System Overview

These three boards form a complete system: Input → Process → Output.
Each board has one job, but all three work together.

🛠️ How to Build Any Stripboard – Universal 6-Step Method

  1. Print the schematic and highlight every input, output and power pin.
    Do NOT place parts until you understand what each pin must connect to.
  2. Mark the power rails.
    • Red = +V rail (top strip)
    • Black = 0V rail (bottom strip)
    Check continuity end-to-end.
  3. Place the IC first.
    Stripboard has no centre gap → cut copper under every pin.
    Pin 1 MUST face left so it matches diagrams.
  4. Add resistors and sensors next.
    Place them so that the required pins sit on isolated strips.
    Check each connection against the schematic: “Does this join the same two nodes?”
  5. Add link wires (one colour per signal).
    If two schematic points connect but stripboard holes don’t touch → add a wire.
    Keep them short and flat to avoid confusion.
  6. Finally, add LEDs, capacitors and terminal blocks.
    Check polarity carefully.
    For electrolytics: long leg = +, short = −.

Rule: Follow the schematic → not the picture.
The stripboard layout is only one of many possible arrangements.

🎨 Stripboard Wire Colour Code (N5 Electronics Standard)

To avoid mistakes, every wire on your stripboard must follow the N5 colour rules:

  • RED = +V (positive supply)
  • BLACK = 0V (ground)
  • Every other signal must use its own unique colour
    (e.g., blue for TempOut, green for SwitchOut, yellow for AND Output, purple for timing node)

Why this matters:
• Helps you trace signals quickly
• Prevents mixing up logic lines
• Matches industry-style colour-coding used in S4–S6 projects

🔧 Troubleshooting Checklist

  • 1. Power rails correct?
    Red = +V runs all the way across.
    Black = 0V runs all the way across.
  • 2. All IC pins isolated?
    Check every red-X track cut. Missing one = chip shorts two pins together.
  • 3. Each signal colour used once?
    If two different signals share a colour, you will mis-trace the board.
  • 4. Capacitor polarity correct?
    Long leg → timing node (2/6)
    Short leg → ground
  • 5. LED polarity correct?
    Flat side / short leg → 0V (for green LEDs)
  • 6. Compare every stripboard connection to the schematic.
    Say out loud: “This pin goes to ___ on the diagram.”

If stuck: Check continuity with a meter → follow the copper strips, not your eyes.

⭐ Part 1 — What the Input Board Does

The Input board creates two clean logic signals that feed into the AND gate:
TempOut (blue) SwitchOut (green)

1 — Identify all components

  • RT — Thermistor
  • R1 — 4.7 kΩ pulldown
  • R2 — 10 kΩ pull-up
  • R3 — 10 kΩ pulldown
  • SW1 — Switch
  • +V rail — top copper strip
  • 0V rail — bottom copper strip

2 — Thermistor voltage divider

RT (to +V) and R1 (to 0V) form a voltage divider. High temperature → low RT → higher TempOut voltage.

3 — Switch voltage divider

  • R2 pulls SwitchOut HIGH
  • R3 pulls SwitchOut LOW
  • SW1 drives the centre pin of the divider

4 — Output lines

  • Blue = TempOut
  • Green = SwitchOut

5 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut

⭐ Part 2 — What the Process Board Does

The Process board uses a 74HC08 AND gate. Output = HIGH only when TempOut AND SwitchOut are HIGH.

1 — Identify parts

  • 74HC08 AND gate IC
  • Using Gate 1 → pins 1 (A), 2 (B), 3 (Y)
  • Pin 14 → +V
  • Pin 7 → 0V
  • Blue → TempOut → pin 1
  • Green → SwitchOut → pin 2
  • Yellow → AND output → Output board

2 — IC orientation

No centre gap → each pin sits on an isolated copper pad. Track cuts isolate all pins.

3 — Power

  • Pin 14 → +V
  • Pin 7 → 0V

4 — Inputs

  • Pin 1 = TempOut
  • Pin 2 = SwitchOut

5 — Output

Pin 3 is the AND output → yellow wire → triggers the 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output

⭐ Part 3 — What the Output Board Does

The Output board contains a 555 astable that flashes green & red LEDs. It only runs when the AND gate output (yellow wire) is HIGH.

1 — Identify all parts

  • 555 IC
  • R4, R5 — timing resistors
  • C1 — timing capacitor
  • Red LEDs — LOW output
  • Green LEDs — HIGH output

2 — Power pins

  • Pin 1 → 0V
  • Pin 8 → +V

3 — Timing network

  • R4: +V → pin 7
  • R5: pin 7 → timing node (pins 2/6)
  • C1: timing node → 0V

4 — LEDs

Green LEDs (HIGH)

  • Pin 3 → resistor → LED → 0V

Red LEDs (LOW)

  • +V → resistor → LED → pin 3

5 — AND gate trigger

Yellow wire from Process → pin 2 of 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Yellow = AND output
  • Blue = 555 output
  • Purple = timing node
