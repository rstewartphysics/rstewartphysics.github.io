Stripboard Builder

Use the tabs below to build each board, then wire them together using screw-terminal blocks.

📥 INPUT BOARD IMAGE HERE
(Switches & sensors: thermistor, LDR, toggle)

Build Steps

1. Place switch and sensors onto the stripboard.
2. Connect each device to the top power rail.
3. Add pulldown resistors for each input line.
4. Route outputs to terminal block OUT1 / OUT2 / OUT3.
🔧 LOGIC BOARD IMAGE HERE
(AND / OR / NOT logic using 74HC08 etc.)

Build Steps

1. Insert ICs so legs bridge the centre gap.
2. Add 10 kΩ resistors to inputs.
3. Connect logic outputs to the terminal marked “TO OUTPUT BOARD”.
💡 OUTPUT BOARD (555) IMAGE HERE
(Matches your “555 new.jpg” layout)

Build Steps

1. Insert NE555 with correct orientation.
2. Add R1 (1 kΩ), R2 (10 kΩ), and C1 (100 μF).
3. Connect LEDs with 680 Ω resistors.
4. Bring power & trigger from the logic board via the terminal block.
