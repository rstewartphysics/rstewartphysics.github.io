Step 1 — Identify all parts (Yenka → Stripboard)

Using the Yenka schematic (/mnt/data/IMG_0073.jpeg): You must be able to point to each part in both the schematic and the stripboard layout.

  • RT — Thermistor — left of board, vertical
  • R1 — 4.7 kΩ pulldown — bottom-left
  • R2 — 10 kΩ pull-up — right side
  • R3 — 10 kΩ pulldown — centre-right
  • SW1 — Switch — three-pin block, right side
  • +5 V rail — red long strip — very top track
  • 0 V rail — black long strip — very bottom track

Why this matters: This board outputs two logic signals (TempOut and SwitchOut) that feed the process board.

Step 2 — Place the power rails

In /mnt/data/IMG_0074 1.jpeg, the top red strip is +V and the bottom black strip is 0V. Confirm both rails are continuous using continuity mode.

Step 3 — Install RT and R1 (thermistor input)

RT and R1 create a voltage divider:

  • RT: between +V (top rail) and TempOut node
  • R1: between TempOut node and 0V (bottom rail)

Common mistake: Connecting RT to 0V instead of +V reverses the behaviour.

Step 4 — Install R2, R3, and SW1 (switch input)

  • R2 (10 kΩ) — +V → SwitchOut
  • R3 (10 kΩ) — SwitchOut → 0V
  • SW1 — centre pin connected to SwitchOut

This produces: SW1 pressed → HIGH, released → LOW.

Step 5 — Confirm the output lines

  • Blue = TempOut
  • Green = SwitchOut

Both run to the terminal block on the right.

Step 6 — Add link wires

  • Blue → TempOut
  • Green → SwitchOut
  • Red → +V extension
  • Black → 0V extension

Rule: If the schematic joins two points but the stripboard does not, add a link wire.

Input Board Complete ✔ — This board now outputs two logic-level signals to the process board.

Process Board – 74HC08 AND Gate

⭐ PROCESS BOARD — 74HC08 AND-Gate Logic Stage
(Matches your Yenka schematic AND block and the stripboard in /mnt/data/IMG_0074.jpeg)

This board takes the two inputs from the Input Board:

  • TempOut (blue wire)
  • SwitchOut (green wire)

…and feeds them into one AND gate inside the 74HC08. The AND output then goes to the Output Board.

Step 1 — Identify all parts (Schematic → Stripboard)

From the Yenka schematic (IMG_0073.jpeg), the Process section contains:

  • IC2a (74HC08) — AND gate — middle of board with track-cut isolation
  • TempOut — blue link — input A
  • SwitchOut — green link — input B
  • +V — top red power rail
  • 0V — bottom black rail
  • AND Output — yellow link — to Output Board

Why this matters: The AND output must only be HIGH when both inputs are HIGH.

Step 2 — Place the 74HC08 IC correctly

Your stripboard has no centre gap, so every pin must sit on an isolated track segment. Your image shows the correct red-X track cuts under every pin.

Orientation: Pin 1 at the notch/dot (top left when viewed overhead).

       _________
  1A  | 1     14 | Vcc (+5 V)
  1B  | 2     13 | 4A
  1Y  | 3     12 | 4B
  2A  | 4     11 | 4Y
  2B  | 5     10 | 3A
  2Y  | 6      9 | 3B
 GND  | 7      8 | 3Y
       ---------

You are using Gate 1 (1A, 1B → 1Y), so you only need pins 1, 2, 3.

Step 3 — Connect the power pins

  • Pin 14 → +V (top red rail)
  • Pin 7 → 0V (bottom black rail)

Check for no accidental copper continuity to other tracks.

Step 4 — Connect TempOut and SwitchOut

Your stripboard shows:

  • Blue → pin 1 (1A)
  • Green → pin 2 (1B)

Each pin must touch only its link wire and its own isolated copper pad.

Step 5 — Route the AND gate output

Pin 3 is the output (1Y). Your yellow vertical link carries this to the right-hand terminal block → Output Board (555 trigger).

Correct behaviour: ANDout → enables 555 only when TempOut AND SwitchOut are TRUE.

Step 6 — Add required link wires

Your board uses colour-coded links:

  • Red → +V
  • Black → 0V
  • Blue → TempOut
  • Green → SwitchOut
  • Yellow → AND Output

During soldering:

  • Use short, neat wires
  • Keep colour-coding consistent
  • Check continuity for all isolated IC pins

Process Board Complete ✔ — The AND gate now outputs a clean digital signal to drive the 555 Output Board.

TempOut (blue) → pin 1, SwitchOut (green) → pin 2.
Pin 3 output (yellow) goes to Output Board.
Pin 14 → +V, Pin 7 → 0V.

Output Board – 555 LED Flasher

⭐ OUTPUT BOARD — 555 Astable LED Flasher
(Matches Yenka schematic + your stripboard /mnt/data/IMG_0077.jpeg)

This board turns the logic output from the Process board into alternating flashing LEDs using the NE555 in astable mode.

Output Board Stripboard Layout (555)

Step 1 — Identify all parts (Schematic → Stripboard)

  • 555 — NE555 timer IC — creates HIGH/LOW pulses
  • R4 (4.7 kΩ) — timing resistor 1 — controls charge rate
  • R5 (10 kΩ) — timing resistor 2 — controls discharge path
  • C1 (100 μF) — timing capacitor — charges & discharges to create flashing
  • R6, R7, R8, R9 (270 Ω) — LED resistors
  • RL1, RL2 — red LEDs — LOW output state
  • GL1, GL2 — green LEDs — HIGH output state
  • +V — red rail
  • 0V — black rail

Your stripboard shows the 555 centered with red-X cuts under each pin and all resistors and LEDs placed exactly as drawn.

Step 2 — Place the 555 with correct track cuts

Your stripboard has no centre gap, so each pin must sit on an isolated copper pad. The red-X cuts provide this.

  • Pin 1 (bottom left) → 0V
  • Pin 8 (top right) → +V
  • Pins 2 and 6 linked — timing node

All your pin isolations and orientation are correct.

Step 3 — Connect the power rails

  • Pin 8 → +V (vertical black strip + yellow link)
  • Pin 1 → 0V (vertical black link)

Pins 4 and 8 are tied HIGH, keeping RESET active.

Step 4 — Build the timing network (R4, R5, C1)

  • R4: +V → Pin 7 (Discharge)
  • R5: Pin 7 → Pins 2/6 (timing node)
  • C1: + leg → Pins 2/6, – leg → 0V

C1 sits bottom-centre; the purple node links R5 → C1 → pins 2/6.

Common mistake: Reversing C1 or putting its negative leg to +V stops oscillation.

Step 5 — Connect AND-gate Output (Trigger)

The yellow wire from the Process Board is the AND output. It must connect to Pin 2 (trigger).

  • Yellow wire enters from left
  • Travels downward
  • Reaches timing node (pins 2/6)

Correct: The flasher only runs when both inputs are TRUE.

Step 6 — Add the LED output section

Green LEDs (HIGH output)

  • Pin 3 → R8 → GL1 → 0V
  • Pin 3 → R9 → GL2 → 0V

Pin 3 is fed by a blue link; LEDs are below resistors with negative legs to ground.

Red LEDs (LOW output)

  • +V → R6 → RL1 → Pin 3
  • +V → R7 → RL2 → Pin 3

Resistors sit above LEDs and feed from the +V rail.

Why they alternate: Green = HIGH, Red = LOW.

Step 7 — Final link wires

  • Blue → 555 output
  • Yellow → AND input
  • Purple → timing node
  • Black → ground
  • Yellow (right) → terminal block output

Rule: If two schematic points connect but stripboard holes don’t, add a link.

⭐ Output Board Complete ✔
Your astable is fully wired: power, timing, trigger input, LEDs, isolated pins, and final output to the system.
