🛠 Build Method — Universal 6-Step Stripboard Process

These six steps work for ANY stripboard project: Input → Process → Output.

Universal 6-Step Method

  1. Print the schematic and highlight inputs, outputs, and power pins.
  2. Mark the power rails.
    Red = +V (top) / Black = 0V (bottom)
  3. Place the IC first.
    Stripboard needs track cuts under each pin.
  4. Add resistors and sensors.
    Ensure correct electrical nodes.
  5. Add link wires.
    If strips don’t touch → you MUST add a wire.
  6. Add LEDs and capacitors last.
    Check polarity.

Rule: Follow the schematic, not the picture.

🎨 Stripboard Colour Code (N5 Standard)

Use a unique colour for each signal.

  • RED = +V
  • BLACK = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output
  • Purple = timing node

This prevents mistakes and improves debugging speed.

Input Board

Yenka – Input Section
Input Stripboard

⭐ Part 1 — What the Input Board Does

The Input board creates two clean logic signals that feed into the AND gate:
TempOut (blue) SwitchOut (green)

1 — Identify all components

  • RT — Thermistor
  • R1 — 4.7 kΩ pulldown
  • R2 — 10 kΩ pull-up
  • R3 — 10 kΩ pulldown
  • SW1 — Switch
  • +V rail — top copper strip
  • 0V rail — bottom copper strip

2 — Thermistor voltage divider

RT (to +V) and R1 (to 0V) form a voltage divider. High temperature → low RT → higher TempOut voltage.

3 — Switch voltage divider

  • R2 pulls SwitchOut HIGH
  • R3 pulls SwitchOut LOW
  • SW1 drives the centre pin of the divider

4 — Output lines

  • Blue = TempOut
  • Green = SwitchOut

5 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut

Input Board Complete ✔

✔ Build Checkpoint

  • Does TempOut change when you warm/cool the thermistor?
  • Does SwitchOut clearly switch between HIGH and LOW?
  • Are RT → TempOut → R1 forming a clean voltage divider?
  • Is each signal wire colour unique (blue = TempOut, green = SwitchOut)?

⚠ Common Mistakes (and How to Fix Them)

  • Thermistor wired to 0V instead of +V → TempOut inverts (fix: RT must go to +V).
  • Switch centre pin on the wrong strip → always HIGH or always LOW (fix: centre pin must touch the SwitchOut node).
  • R2 and R3 swapped → output floats or becomes noisy (fix: R2 is pull-up, R3 is pull-down).
  • Signal wires sharing colours → easy to mis-trace (fix: TempOut = blue, SwitchOut = green).

Process Board – AND Gate

Yenka – AND Section
Process Stripboard

⭐ Part 2 — What the Process Board Does

The Process board uses a 74HC08 AND gate. Output = HIGH only when TempOut AND SwitchOut are HIGH.

1 — Identify parts

  • 74HC08 AND gate IC
  • Using Gate 1 → pins 1 (A), 2 (B), 3 (Y)
  • Pin 14 → +V
  • Pin 7 → 0V
  • Blue → TempOut → pin 1
  • Green → SwitchOut → pin 2
  • Yellow → AND output → Output board

2 — IC orientation

No centre gap → each pin sits on an isolated copper pad. Track cuts isolate all pins.

3 — Power

  • Pin 14 → +V
  • Pin 7 → 0V

4 — Inputs

  • Pin 1 = TempOut
  • Pin 2 = SwitchOut

5 — Output

Pin 3 is the AND output → yellow wire → triggers the 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Blue = TempOut
  • Green = SwitchOut
  • Yellow = AND output

Process Board Complete ✔

✔ Build Checkpoint

  • Does pin 1 (TempOut) go HIGH/LOW correctly?
  • Does pin 2 (SwitchOut) go HIGH/LOW correctly?
  • Does pin 3 (AND Output) only go HIGH when BOTH inputs are HIGH?
  • Are all IC pins isolated by confirmed track cuts?

⚠ Common Mistakes (and How to Fix Them)

  • Pin numbers misread → AND gate behaves incorrectly (fix: notch marks pin 1; check orientation).
  • Missing track cuts → two IC pins short together (fix: verify every red-X cut individually).
  • Blue/green inputs placed one strip off → wrong signal into pin 1 or 2 (fix: continuity-test each input).
  • AND output wired to wrong strip → 555 never starts (fix: pin 3 → yellow wire → Output board).

Output Board – 555 LED Flasher

Output Stripboard

⭐ Part 3 — What the Output Board Does

The Output board contains a 555 astable that flashes green & red LEDs. It only runs when the AND gate output (yellow wire) is HIGH.

1 — Identify all parts

  • 555 IC
  • R4, R5 — timing resistors
  • C1 — timing capacitor
  • Red LEDs — LOW output
  • Green LEDs — HIGH output

2 — Power pins

  • Pin 1 → 0V
  • Pin 8 → +V

3 — Timing network

  • R4: +V → pin 7
  • R5: pin 7 → timing node (pins 2/6)
  • C1: timing node → 0V

4 — LEDs

Green LEDs (HIGH)

  • Pin 3 → resistor → LED → 0V

Red LEDs (LOW)

  • +V → resistor → LED → pin 3

5 — AND gate trigger

Yellow wire from Process → pin 2 of 555.

6 — Link wires

  • Red = +V
  • Black = 0V
  • Yellow = AND output
  • Blue = 555 output
  • Purple = timing node

Output Board Complete ✔

✔ Build Checkpoint

  • Does the 555 output (pin 3) toggle between HIGH and LOW?
  • Do green LEDs light only on HIGH?
  • Do red LEDs light only on LOW?
  • Is C1 polarity correct?
  • Is the yellow AND-signal wire definitely reaching pin 2?

⚠ Common Mistakes (and How to Fix Them)

  • C1 reversed → no oscillation (fix: long leg → pins 2/6, short leg → 0V).
  • Pins 2 and 6 not linked → timing node missing (fix: add vertical link).
  • Pin 3 misused → LEDs don’t alternate (fix: blue link must go from pin 3 to LED network).
  • R4 & R5 swapped → timing becomes incorrect (fix: R4 = +V→7, R5 = 7→2/6).
  • LEDs reversed → no light (fix: check polarity carefully).
