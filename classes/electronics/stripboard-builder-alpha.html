The Stripboard Builder has moved — and it is now in two parts

The alpha is finished. What was one page behind a row of tabs is now two, so you can go straight to the one you want.

Learn to Plan a Stripboard Schematic →

The taught part, marked. Five tasks on the same set of boards: trace what the copper joins, convert a circuit diagram into a layout, find the one fault on a finished board, read a board backwards to the circuit it builds, and mark the test points a marker expects. It opens on a page of the rules and what each task asks of you.

Plan your own Stripboard Schematic →

The blank board. The whole parts box, either board size, and nothing marked — because there is no right answer. Build the sub-system you have designed, and check it could actually be built before you commit it to your planning sheet.
