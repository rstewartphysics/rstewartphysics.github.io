{% comment %} Generic resource marks — slides, notes, papers, quizzes, video and so on. These are the same in every subject, so they live here rather than in a subject sprite, and any hub can include them alongside its own topic marks. The accent is var(--ic-accent, var(--accent)) so a context can remap it: on a coloured tile band the accent would otherwise be invisible against the band. See .tile-head. Paint must be inline style= on every shape: document CSS cannot reach into a shadow tree and class-styled shapes render solid black. Custom properties DO inherit in. {% endcomment %}
