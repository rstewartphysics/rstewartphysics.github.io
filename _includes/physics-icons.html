{% comment %} Physics icon sprite — one drawn mark per topic, shared across the Physics levels so a topic carries the same symbol from S3 to Higher: the hub tiles, the slides hub and the topic pages. S3 Electricity 1 and Higher current/p.d./resistance are the same idea, so they are the same mark. The accent is var(--ic-accent, --accent) so a context can remap it: on a coloured tile band the accent would otherwise be invisible against the band. See .tile-head.
