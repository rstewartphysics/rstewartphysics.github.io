# Engineering Science assets

This folder structure is for new Engineering Science resources used on mrstewartphysics.co.uk.

## Purpose

- Keep Engineering Science uploads organised by level and topic.
- Separate shared assets from topic-specific assets.
- Make file paths predictable for root-relative links in pages.

## Naming convention

Use this format for uploaded files:

`level-engineering-science-topic-resource-type-short-title.ext`

Examples:

- `s3-engineering-science-what-is-an-engineer-booklet.pdf`
- `s3-engineering-science-energy-student-booklet.pdf`
- `n5-engineering-science-energy-efficiency-booklet.pdf`
- `n5-engineering-science-data-sheet.pdf`
- `n5-engineering-science-assignment-planning-template.pdf`
- `n5-engineering-science-mechanisms-revision-questions.pdf`
- `engineering-science-banner.png`

## File naming rules

- Use lowercase.
- Use hyphens instead of spaces.
- Do not use apostrophes, brackets, ampersands or special characters.
- Keep page-specific files inside the matching topic folder.
- Keep resources used across more than one Engineering Science page inside `/assets/engineering-science/shared/`.
- Keep Engineering Science banners inside `/assets/engineering-science/banners/`.
- Keep decorative images, logos and diagrams inside `/assets/engineering-science/images/`.
- Use root-relative links on pages, for example:
  `/assets/engineering-science/s3/what-is-an-engineer/s3-engineering-science-what-is-an-engineer-booklet.pdf`
